## What landed

- `src/lib/reader/projection/` holds the producer core and the browser view:
  - `text.ts`: term reduction;
  - `embed.ts`: corpus, similarity, edges, warm start, Procrustes, document;
  - `tsne.ts`: exact t-SNE;
  - `scene.ts`: the browser-safe join with routeable posts, plus arrow-key
    navigation.
- `scripts/generate-posts-projection.mts` writes the committed artifact
  `src/lib/data/posts-projection.v1.json`. The recipes are
  `just posts-projection` (warm), `just posts-projection-cold` and
  `just posts-projection-check`.
- `ReaderConstellation.svelte` gains two views, **Similarity map** (SVG, one
  roving tab stop, arrow keys to nearby posts, Escape, `?focus=<slug>`) and
  **Similar posts** (the list equivalent: every placed post with its nearest
  neighbours). The existing Constellation and Year tree views are unchanged and
  still the default.

## Decisions

1. **Committed artifact, not generated in CI.** Warm-start stability needs the
   previous coordinates as an input, and a committed file gives a reviewable
   diff when the map moves. The build therefore does no numerical work. A new
   post does not fail CI: it shows up as "N newer posts are not on the map yet"
   until someone runs `just posts-projection`. CI does fail when the method or
   configuration changes without a refit, or when the file holds a slug that is
   not `published: true` (`committed-projection.test.ts`).
2. **TypeScript port, not the spear Python.** The method is spear
   `profile/refresh/embed.py` at 1b8b27863f90 (`tfidf-jaccard-exact-tsne-2`):
   the same weights, the same edge rule, the same warm-start rule and the same
   Procrustes step. It is ported so that neither the blog build nor CI needs the
   pinned numpy/scikit-learn shell. The coordinates are reproducible
   (byte-identical for the same inputs on one JS engine) but **not**
   bit-compatible with scikit-learn, because numpy's RandomState is replaced by
   seeded mulberry32 plus Box-Muller. The revision is recorded as
   `tfidf-jaccard-exact-tsne-2/ts-port-1`.
3. **Random init, not PCA.** The spec said `init="pca"`, but scikit-learn
   rejects PCA init with `metric="precomputed"`. spear uses seeded random init,
   and so does this port.
4. **Perplexity 15** (the spec's starting value), capped at (n-1)/3. Title,
   description and tag tokens carry weight 3. The body contributes its top 120
   terms after code, Svelte script/style, markup, link targets and URLs are
   removed. Dates, order, featured state and colour never enter the fit.
5. **No runtime fetch.** The JSON is a static import, about 14 KB minified
   before gzip. With the flag off, nothing renders and nothing is requested.
6. **Plain SVG, not the #288 WebGL engine.** About 140 nodes do not need WebGL,
   and #288 is not merged.

## First fit (cold, 2026-10-06)

The fit covers 140 published posts and draws 243 edges. KL is 0.2767 and
neighbour overlap at k=3 is 0.679. In a warm-start probe that added one post,
the mean display shift was 0.0099 and the maximum 0.046 (unit square).
